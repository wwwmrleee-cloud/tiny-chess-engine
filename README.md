A 0x88 negamax chess engine in at most 4,096 bytes of Python: alpha-beta search with a transposition table, killer and history move ordering, null-move pruning, late-move reduction, PVS and capture quiescence, searching to a fixed node budget so every game replays deterministically.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
